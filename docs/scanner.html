Scanner local de segredos

Execute uma análise real no navegador com sete regras heurísticas adaptadas do SecurePath CLI. Os arquivos escolhidos e o texto permanecem no dispositivo: esta página não envia o conteúdo à rede.

01 / Dados de entrada

Até 5 MiB por arquivo e 20 MiB por lote. Não envia nem altera arquivos. Use apenas dados autorizados; os nomes dos arquivos aparecem no relatório.

02 / Relatório

Pronto para análise.

Limites e transparência
Esta é uma implementação JavaScript para demonstração, não a execução do Python no navegador. Aplica as sete regras nativas a texto e arquivos selecionados; não percorre diretórios, não lê histórico Git, não executa regras externas e não valida credenciais. Diferenças de regex e decodificação entre JavaScript e Python podem afetar casos Unicode ou UTF-8 inválido. Um alerta é registrado por regra e linha, sem imprimir o valor encontrado. Ausência de alertas não garante ausência de segredos.
