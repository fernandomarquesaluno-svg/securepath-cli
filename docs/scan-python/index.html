Scanner Python no navegador

O núcleo original artefatos.py é executado em um Web Worker usando Pyodide 0.27.7. A cópia do Python e o runtime são servidos pelo próprio site. Não enviamos o conteúdo dos arquivos a terceiros. Use somente arquivos autorizados e exemplos fictícios.

Entrada

Arraste arquivos aqui
Configurações avançadas

Use somente expressões regulares confiáveis. O cancelamento encerra o worker; uma análise sem progresso por 30 segundos também é interrompida.

Pronto. Limites: 500 arquivos, 25 MiB no total, 5 MiB por arquivo.

Resultados

Nenhuma análise realizada.

Limitações

Execução sequencial: o navegador não reproduz o paralelismo da CLI. A seleção de diretórios depende do navegador. Arquivos binários e grandes são ignorados pelo núcleo Python; a exclusão de diretórios usa caminhos relativos disponibilizados pelo seletor. Alertas indicam padrões, não a validade de credenciais. O runtime exige download inicial e memória do navegador.
