01 / O PROBLEMA

Uma credencial no código pode virar um incidente.

Senhas e tokens inseridos por engano em repositórios ou configurações podem abrir caminho para acessos não autorizados. A análise estática oferece uma camada adicional de revisão antes da publicação.

01!

Exposição acidental

Chaves, tokens e senhas podem permanecer em arquivos e chegar a commits ou pacotes.

RISCO
02⌕

Inspeção automatizada

O SecurePath busca padrões suspeitos linha a linha, com regras Regex transparentes e auditáveis.

RESPOSTA
03✓

Alerta sem vazamento

A saída informa categoria, caminho e linha, sem repetir a possível credencial encontrada.

PROTEÇÃO DE SAÍDA
IMPORTANTE Um alerta é um indício, não prova de que a credencial é real ou está ativa. Um resultado limpo também não garante ausência de segredos.

04 / MOTOR DE DETECÇÃO

Sete regras. Sete pontos de inspeção.

Explore as regras SEC001 a SEC007 que compõem a varredura heurística. Selecione uma regra para entender seu alvo e os limites de detecção.

SEC001REGEX HEURÍSTICA
⌕

AWS Access Key ID

Procura identificadores de chave de acesso AWS que começam com AKIA e seguem o formato previsto pela regra.

FORMATO RECONHECIDOAKIA + 16 caracteres A–Z / 0–9
O QUE O ALERTA NÃO PROVA

Não confirma que o identificador existe, está ativo ou possui permissões.

Uma arquitetura pequena, legível e auditável.

O projeto mantém a coleta, as regras e a apresentação dos resultados separadas dentro de um único script Python.

LIMITAÇÕES REAIS

Reconhecer padrões não é validar credenciais.

  • Falsos positivos e falsos negativos são possíveis.
  • Não inspeciona histórico Git, arquivos compactados ou conteúdos criptografados.
  • Ignora links simbólicos, determinadas pastas, binários e arquivos acima do limite.
  • Não mede precisão/recall em bases reais e não substitui revisão humana.
  • Os caminhos listados no relatório podem conter informações sensíveis.
07 / REPRODUZA VOCÊ MESMO

Do atlas para seu terminal.

Para executar a ferramenta de verdade, use Python 3.9+ e o repositório. A análise do código acontece localmente, sem serviço externo.

git clone https://github.com/fernandomarquesaluno-svg/securepath-cli.git
cd securepath-cli
python3 -m unittest discover -s tests -v
python3 artefatos.py demonstracao
python3 artefatos.py demonstracao --format json
Use apenas arquivos que você tem autorização para analisar. Não publique relatórios de projetos privados.
